# ITILSuite Frontend

Modern, high-performance web interface for **ITILSuite**.

## Tech Stack
* **React 19**
* **TypeScript**
* **Vite**
* **Lucide React** (Enterprise UI Icons)

## Development
```bash
npm install
npm run dev
```

The application will be served at `http://localhost:5173`.
Make sure the backend is running at `http://localhost:8081` (configurable via `VITE_API_URL` in `.env`).

## Production Build
```bash
npm run build
```
